# 创作者研究补充

在选题、账号对标、口播参考和创作建议任务中读取。

- 保持用户指定的平台、时间段和受众；缺数据时说明缺口，不自动换平台作为同等证据。
- 没有指定平台时，给出与目标相关的选择，并说明实际采样平台。
- 公开热榜、搜索结果和话题频率属于趋势线索。播放、互动、完播和转化需要相应原始字段；前者不能替代后者。
- 一次搜索无法证明增长。没有可比时间窗口时，用“近期样本中出现”或“值得验证”，不要写“快速增长”。
- 同账号、同平台的近期样本可以形成表现基线，注明样本量、时间窗与选择偏差。样本不足时不包装为稳健结论。
- 没有播放量时保留 views=null，不用点赞换算播放、完播或流量。不用公开互动承诺用户能获得多少播放或粉丝。
- 评论结论记录样本量、取样位置和覆盖账号；热门评论不代表所有观众，多个帖子出现同类问题比单条评论更有说服力。
- 将选题与用户的受众、经验、可展示素材和制作能力匹配；没有账号定位时明确适配判断属于暂定。
- 引用口播原稿需要用户提供或可核实的字幕。标题、封面和统计数据不能还原丢失原稿；原稿缺失时标记 script_lost。
- 对标内容用于识别事实、问题和方法。实际创作采用用户自己的经验、证据和表达，不沿用来源独特的开头、措辞、顺序或结尾。
- 推荐选题附：具体问题、样本证据、原始链接、取样时间、账号适配理由、素材需求和置信度。资料不足时可以不给数值分数。
- 样本中的供给少只表示搜索覆盖范围内的现象，不能断言整个赛道无人做或保证低竞争。
