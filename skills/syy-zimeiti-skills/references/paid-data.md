# 可选付费数据连接

只有用户明确要求使用具体外部数据服务，并已了解该服务的独立计费后才走此路径。即使环境变量已有密钥，也不代表这次任务授权产生费用。Codex 和 WorkBuddy 的模型额度不支付 TikHub 或平台商业接口的费用。

原仓库保留 `scripts/tikhub_mcp.py` 和 `scripts/estimate_cost.py`，供明确选择 TikHub 的任务使用。先核实当前账户余额、接口价格与免费额度适用性，再用 `status`、`health`、`platforms`、`list-tools` 发现工具与参数。少量样本验证成功后记录请求量和费用，再决定是否扩大；402 停止该平台调用。密钥只从本地环境变量读取，不写入报告或仓库。远程接口的实际字段和费用以当次返回与服务商账户为准。

若用户只要求使用 Codex/WorkBuddy 自身额度，不要检查 TikHub Key，不要调用上述脚本的远程子命令，也不要自动切换到其他付费数据源。
