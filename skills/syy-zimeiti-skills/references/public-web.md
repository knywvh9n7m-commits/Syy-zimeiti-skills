# 公开网页采样（Codex / WorkBuddy 默认路径）

使用当前宿主已经提供的网页搜索、浏览器和公开页面读取能力。模型负责拟定查询、去重、分析与写报告；宿主额度只覆盖其自身约定的使用量，不能替第三方数据商付费。不要自行接入需要 API Key、充值或单独计费的数据服务。

## 采样

1. 固定主题、平台、地区/语言、时间窗和搜索截止时间。用户说“全网”时，先选研究价值最高的 3–5 个平台，并分别记录能否检索到公开内容。
2. 对每个平台使用 2–4 组不同表达的关键词；可以用 `site:平台域名`、平台原生搜索、日期筛选与账号搜索，但不能把搜索引擎索引视为平台全量数据。记录查询词、排序/筛选、搜索页数、命中数和实际打开数。
3. 先打开 1–3 个结果检查：是否为原始内容页、视频还是图文、发布日期及其时区、作者、标题、公开播放/点赞/评论/收藏/分享、评论和字幕能否读取。搜索摘要与页面字段冲突时以原始页面为准；仍冲突则标记不确定。
4. 扩大到对研究问题足够的可见样本，去重转载、合集页、推荐侧栏和相同视频的不同入口。只引用实际读过的评论/字幕。记录每个平台的实际覆盖和缺失字段。
5. 每条关键结论保留原始链接、采集时间、具体字段与样本数。无法读取时填 `null` 或“未核实”；不从点赞估算播放、从标题还原口播，也不把发布会新闻热度算作视频播放热度。

## 模式映射

| 研究模式 | 公开网页可做什么 | 何时降级 |
|---|---|---|
| 趋势扫描 | 比较已打开的近期样本主题、发布日期、标题和可见指标 | 无可比前后时段：只写“近期出现” |
| 对标与账号审计 | 查看公开主页和多条作品，比较主题、形式与可见指标 | 主页不可访问或作品不足：只列候选，不建表现基线 |
| 高表现内容拆解 | 同平台同账号多条可比作品才算相对表现；结合可核字幕/画面分析 | 只有单条或缺指标：写“高可见数案例”，不称爆款 |
| 评论需求 | 从多个可读帖子的评论提炼问题，给出数量与实例 | 评论不可读：标记缺口，不推断观众需求 |
| 内容空白与选题 | 将可见供给、可见评论和用户定位/素材结合 | 样本稀疏：标记待验证假设，不宣称全平台没人做 |
| 跨平台比较 | 用等价概念和各平台内部的可见证据比较主题/表达 | 指标定义不同：不直接排名播放、浏览或收藏 |

## 报告范围用语

写“检索了 A/B 平台，打开并核对各 N 条，时间窗 X；C 平台公开页面不可访问”，不要写“搜遍全网”。区分直接观测、计算结果、分析推断和待验证假设。用户要求具体选题时，优先给可拍的角度、自己的素材需求和证据置信度。
